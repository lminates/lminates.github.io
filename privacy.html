Privacy policy

Last updated: 2 November 2026

Nine to Free Studio ("the app") is a private tool used only by the owner of the Nine to Free YouTube channel, on their own computer. This policy explains which Google user data the app uses and how.

Data the app accesses

  • YouTube upload access (https://www.googleapis.com/auth/youtube.upload): to upload videos, titles, descriptions, tags and thumbnails that the owner has approved, to the owner's own channel.
  • YouTube read-only access (https://www.googleapis.com/auth/youtube.readonly): to show the owner their own channel statistics (subscribers, views, video list).

How the data is used and stored

  • The data is used only to provide the features above to the channel owner.
  • The OAuth access token is stored only on the owner's own computer. It is never sent to any server other than Google's.
  • Channel statistics are kept in the computer's memory for a few minutes to show them, and are not stored permanently.
  • The app does not sell, share, transfer or disclose Google user data to anyone. It does not use the data for advertising, and it does not use it to train AI models.

Google API Services

The app uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service and the Google Privacy Policy. The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

You can revoke the app's access at any time on myaccount.google.com/permissions. Deleting the token file on the computer removes all stored authorization data. Videos uploaded to YouTube can be managed or deleted in YouTube Studio.
